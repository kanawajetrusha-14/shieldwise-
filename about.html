ABOUT THE PROJECT

What is ShieldWise?

ShieldWise is an educational web platform developed for a Phishing, Scam and Fraud Detection Awareness Program.

The platform provides easy-to-understand information about different types of online scams and teaches users how to identify suspicious activities.

It also provides interactive tools such as a scam detection checker, safety quiz, safety checklist and learning resources.

🎯

Project Purpose

  • ✔ Increase digital safety awareness
  • ✔ Explain common online scams
  • ✔ Teach users to identify warning signs
  • ✔ Encourage safe online behaviour
  • ✔ Promote responsible digital habits
